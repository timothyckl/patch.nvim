# patch 

A simple agentic inline code editor for NeoVim.

Built with [pi-ai](#https://github.com/earendil-works/pi/tree/main/packages/ai) package.

## How it works

1. Enter Visual Line (`Shift + v`) mode, highlight some text or empty space.
2. Send an instruction (e.g. "Refactor this function", "Add doc strings.", "Add type hints").
3. Wait for suggestion. Accept,Reject,Retry.
